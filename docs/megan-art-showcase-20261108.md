# Megan’s custom artwork showcase

Added eight owner-supplied images in four project galleries: three commissioned dog portraits, three custom fantasy pieces, a duck collaboration, and a zebra collaboration.

Megan receives artwork credit for all eight ACEOs. The duck and zebra projects appear in both Megan’s and Jess’s galleries, with Jess specifically credited for the 3D companions’ paint designs. The descriptions identify the displayed image as the ACEO; no companion photograph or sculpture authorship is invented.

Web JPEGs preserve the full photographs, normalize orientation, remove metadata, and limit height to 2000 pixels. Original files remain unchanged. Descriptive labels do not claim official artwork titles.
