# Alex’s dinosaur photography showcase

Added two owner-supplied photographs to Alex’s project gallery with photography credit, descriptive alt text, image selection, and the existing enlarged-image viewer. This replaces Alex’s empty gallery placeholder.

Descriptive labels do not claim official artwork titles or credit Alex with making the photographed figures. Web JPEGs preserve the full compositions, normalize orientation, remove metadata, and limit width to 2000 pixels. Original photographs remain unchanged.

Validation passed: TypeScript, whitespace checks, production build, staged and public smoke checks, and live browser review including switching to the second photograph. Both image assets returned HTTP 200.
